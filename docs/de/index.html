IsleBar

Deine Windows 11-Taskleiste, lebendig. Frag Claude Code oder Codex direkt im Suchfeld — und sieh, ob es arbeitet, dich braucht oder fertig ist.

Für Windows 11 herunterladen Auf GitHub ansehen
Kostenlos · Open Source (MIT) · Kein Konto · Privat von Anfang an

Passt perfekt zu

  • Claude Code oder Codex CLI — frag direkt aus der Leiste und sieh: arbeitet · braucht dich · fertig.
  • Everything (voidtools, kostenlos) — drück Tab und durchsuche sofort jede Datei auf deinem PC.
  • Jeder Webbrowser — dort öffnen sich die Ergebnisse der Websuche.

IsleBar läuft unter Windows 11 (x64), wenn das Suchfeld der Taskleiste als Feld oder Symbol angezeigt wird.

Wisse, wo dein Agent steht.

Arbeitet. Braucht dich. Fertig. Das Suchfeld sagt es dir — so kannst du wegschauen, während Claude Code oder Codex arbeitet. Ein orangefarbener Rand heißt: Es wartet auf deine Antwort. Grün heißt: fertig.

Ein Feld. Und alles andere auch.

Die Pille bleibt, wo das Suchfeld immer war. Nur der Inhalt ändert sich.

Frag direkt aus der Taskleiste.

Klick auf die Pille oder drück Ctrl+Alt+C, tipp ein, was erledigt werden soll, und drück Enter. Ein Terminal öffnet sich und startet Claude Code oder Codex mit deiner Frage.

  • ↑ ↓ holen deine letzten 50 Fragen zurück.
  • Lange Fragen erscheinen als Vorschau über der Leiste; Shift+Enter öffnet ein mehrzeiliges Feld.
  • Der ⌄-Button merkt sich deine Optionen: Sitzung, Modell, Aufwand, Berechtigungen, Fernsteuerung.

Datei ablegen, dann fragen.

Zieh einen Screenshot oder ein Log auf die Pille — der Pfad landet im Feld, bereit für deine Frage.

  • Leg in den Einstellungen einen Ablege-Befehl fest, damit das Ablegen etwas anderes tut.
  • So nutze ich es: Abgelegte Dateien gehen über ein kleines eigenes Skript per Telegram direkt auf mein Handy.

Codex auch.

Codex CLI bekommt genau dasselbe arbeitet · braucht dich · fertig. Das Logo wird aus der Codex-Erweiterung gelesen, die schon auf deinem PC ist — IsleBar liefert kein OpenAI-Logo mit.

  • Orange — der Agent fragt dich etwas. Antworte im Terminal, und er arbeitet weiter.
  • Grün — fertig, mit einem sanften Ton. Bleibt, bis du hinschaust, klickst oder die Sitzung schließt.
  • Mehrere Sitzungen? Die dringendste wird angezeigt, ein kleiner Punkt zeigt, dass es noch mehr gibt.
  • Rot — das Nutzungslimit des Tarifs ist erreicht (mit Uhrzeit des Zurücksetzens) oder ein Durchlauf brach mit einem Fehler ab, samt Grund. Bei 90 % eines Zeitfensters kommt vorher ein Hinweis.

Timer mit zwei Tastendrücken.

Tipp 25m, 90s oder 1h 30m und drück Enter. Nur die Ziffern, die sich ändern, rollen weiter.

  • Mit der Maus darüber: Pause und Stopp. Am Ende ertönt ein Ton und die Pille wird grün.
  • Rechtsklick für Schnell-Timer, Pomodoro (25 / 5 / 15 Minuten, anpassbar) und eine Stoppuhr.

Jede Datei, sofort.

Drück Tab und tipp los — Treffer von allen Laufwerken erscheinen schon beim Tippen über der Taskleiste, angetrieben von Everything.

  • Enter öffnet, Ctrl+Enter zeigt die Datei im Explorer, Esc bringt dich zurück.
  • Noch einmal Tab für die Websuche, mit einer Suchmaschine passend zu deiner Sprache.

Downloads auf einen Blick.

Downloads aus Chrome, Edge, Firefox und anderen Browsern werden angezeigt, solange sie laufen, und am Ende mit Fertig und dem Dateinamen. Ein Klick zeigt die Datei im Explorer.

Musik in den Farben des Albums.

Spotify, YouTube im Browser und die meisten Player erscheinen mit Albumcover, Pegelbalken und einer Fortschrittslinie in der Farbe des Albums. Mit der Maus darüber: ⏮ ⏯ ⏭.

Wird ein Agent mitten im Song fertig, leuchtet der grüne Rand auf, ohne die Musik zu verdecken.

Leise Hinweise.

Kopfhörer, Laden, Internet, kopierter Text, hohe CPU- oder Speicherlast, Fokussitzungen, Termine, Mikrofon oder Kamera in Benutzung — alles erscheint kurz und macht dann wieder Platz. Keine Pop-ups.

Jede Farbe hat genau eine Bedeutung: Orange, wenn ein Agent auf deine Antwort wartet, Rot, wenn etwas zu tun ist — Akku fast leer oder ein Agent wegen Nutzungslimit oder Fehler gestoppt — und Grün, wenn etwas fertig ist. Bei „Nicht stören“ bleibt der Ton aus, und bei Spielen und Videos im Vollbild lässt er sich stummschalten.

Hell und dunkel.

IsleBar folgt deinem Windows-Design und färbt sich sofort um, wenn du wechselst — ganz ohne Neustart.

Fragen

Ist es kostenlos?

Ja — kostenlos und Open Source unter der MIT-Lizenz. Fixes, Ideen und Feedback sind auf GitHub jederzeit willkommen.

Ist das eine Dynamic Island für Windows?

Im Geist schon: eine Live-Leiste im Dynamic-Island-Stil, aber sie sitzt in der Windows-11-Taskleiste, wo das Suchfeld war, statt über dem Bildschirm zu schweben. Eine eigenständige App, kein Apple-Produkt.

Wie werde ich unter Windows benachrichtigt, wenn Claude Code oder Codex fertig ist?

IsleBar installieren und Claude Code / Codex verbinden (ein Häkchen im Setup). Die Leiste wird orange, wenn der Agent deine Antwort braucht, und grün mit einem leisen Ton, wenn er fertig ist.

Brauche ich Claude Code oder Codex?

Nur für den KI-Teil — Fragen aus der Leiste und die Anzeige arbeitet · braucht dich · fertig. Musik, Timer, Downloads und Hinweise funktionieren auch ohne; die Dateisuche braucht Everything.

Werden meine Daten irgendwohin gesendet?

Nein. Es läuft auf deinem PC. Absturzberichte sind optional und enthalten nur den Fehler, die Versionen und Basisdaten zum Gerät — niemals Fenstertitel, Dateien, Prompts oder deine IP. Datenschutzerklärung.

Windows meldet „Der Computer wurde durch Windows geschützt“.

Wähle Weitere Informationen → Trotzdem ausführen. Die Code-Signierung ist in Arbeit.

Wie entferne ich es?

Einstellungen › Apps › IsleBar › Deinstallieren. Das normale Suchfeld kehrt zurück, und die Hooks von IsleBar werden entfernt (Store-Version: zuerst die Claude-Code-/Codex-Verbindung in den IsleBar-Einstellungen ausschalten).

Welche Sprachen?

English, 简体中文, 繁體中文, Français, Deutsch, Italiano, 日本語, 한국어, Português, Español — IsleBar folgt deiner Windows-Sprache.
