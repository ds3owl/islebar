Tu barra de tareas de Windows 11, viva. Pregunta a Claude Code o Codex desde el cuadro de búsqueda — y mira cuándo está trabajando, te necesita o ha terminado.

Funciona genial con

  • Claude Code o Codex CLI — pregunta desde la barra y mira: trabajando · te necesita · listo.
  • Everything (voidtools, gratis) — pulsa Tab para buscar al instante cualquier archivo de tu PC.
  • Cualquier navegador — ahí se abren los resultados de la búsqueda web.

IsleBar funciona en Windows 11 (x64), con el cuadro de búsqueda de la barra de tareas mostrado como cuadro o como icono.

Sabe en qué está tu agente.

Trabajando. Te necesita. Listo. El cuadro de búsqueda te lo dice — así puedes apartar la vista mientras Claude Code o Codex trabaja. Un borde naranja significa que espera tu respuesta; verde, que ha terminado.

Un cuadro. Y todo lo demás.

La píldora se queda donde siempre estuvo el cuadro de búsqueda. Solo cambia lo que hay dentro.

Pregunta desde la barra de tareas.

Haz clic en la píldora o pulsa Ctrl+Alt+C, escribe lo que quieres hacer y pulsa Enter. Se abre un terminal que ejecuta Claude Code o Codex con tu pregunta.

  • ↑ ↓ recuperan tus últimas 50 preguntas.
  • Las preguntas largas tienen una vista previa sobre la barra; Shift+Enter abre un cuadro de varias líneas.
  • El botón ⌄ guarda tus opciones: sesión, modelo, esfuerzo, permisos, control remoto.

Suelta un archivo y pregunta.

Suelta una captura o un log en la píldora — su ruta aparece en el cuadro, lista para tu pregunta.

  • Define un Comando al soltar en Configuración para que soltar haga otra cosa.
  • Cómo lo uso yo: los archivos que suelto van directos a mi móvil por Telegram, mediante un pequeño script que hice yo mismo.

Codex, también.

Codex CLI tiene exactamente el mismo trabajando · te necesita · listo. Su icono se lee de la extensión de Codex que ya tienes en tu PC — IsleBar no incluye ningún logo de OpenAI.

  • Naranja — el agente te está preguntando algo. Responde en el terminal y vuelve a trabajar.
  • Verde — listo, con un sonido suave. Se queda hasta que miras, haces clic o cierras la sesión.
  • ¿Varias sesiones? Se muestra la más urgente, y un puntito indica que hay más.
  • Rojo — se alcanzó el límite de uso del plan (con la hora en que se restablece) o un turno se detuvo por un error, con el motivo. Al 90 % de un periodo recibes antes un aviso.

Temporizadores en dos teclas.

Escribe 25m, 90s o 1h 30m y pulsa Enter. Solo giran los dígitos que cambian.

  • Pasa el ratón por encima para pausar y detener. Al terminar suena un aviso y la píldora se pone verde.
  • Clic derecho para temporizadores rápidos, Pomodoro (25 / 5 / 15 minutos, ajustables) y un Cronómetro.

Cualquier archivo, al instante.

Pulsa Tab y escribe — los resultados de todas las unidades aparecen sobre la barra de tareas mientras escribes, gracias a Everything.

  • Enter abre, Ctrl+Enter lo muestra en el Explorador de archivos, Esc te devuelve.
  • Tab otra vez para buscar en la web, con un buscador acorde a tu idioma.

Descargas, de un vistazo.

Las descargas de Chrome, Edge, Firefox y otros navegadores se muestran mientras avanzan, y con Listo y el nombre del archivo al terminar. Haz clic para ver el archivo en el Explorador de archivos.

Música con los colores del álbum.

Spotify, YouTube en tu navegador y la mayoría de reproductores aparecen con carátula, barras de nivel y una línea de progreso del color del álbum. Pasa el ratón para ⏮ ⏯ ⏭.

Si un agente termina a mitad de canción, el borde verde se enciende sin ocultar la música.

Avisos discretos.

Auriculares, carga, internet, texto copiado, CPU o memoria al límite, sesiones de concentración, eventos del calendario, micrófono o cámara en uso — cada uno aparece un momento y luego se aparta. Sin ventanas emergentes.

Cada color significa una sola cosa: naranja cuando un agente espera tu respuesta, rojo cuando hay que actuar — batería baja, o un agente detenido por su límite de uso o un error — y verde cuando algo terminó. El sonido se silencia en No molestar y puede silenciarse en juegos y vídeos a pantalla completa.

Claro y oscuro.

IsleBar sigue el tema de Windows y cambia de color en cuanto lo cambias — sin reiniciar.

Preguntas

¿Es gratis?

Sí — gratis y de código abierto bajo la Licencia MIT. Correcciones, ideas y comentarios son bienvenidos en GitHub.

¿Cómo recibo un aviso en Windows cuando Claude Code o Codex termina?

Instala IsleBar y conecta Claude Code / Codex (una casilla en el instalador). La barra se pone naranja cuando el agente necesita tu respuesta y verde con un sonido suave cuando termina.

¿Necesito Claude Code o Codex?

Solo para la parte de IA — preguntar desde la barra y ver trabajando · te necesita · listo. La música, los temporizadores, las descargas y los avisos funcionan sin ellos; la búsqueda de archivos necesita Everything.

¿Envía mis datos a algún sitio?

No. Funciona en tu PC. Los informes de errores son opcionales y solo incluyen el error, las versiones y datos básicos del equipo — nunca títulos, archivos, prompts ni tu IP. Política de privacidad.

Windows dice “Windows protegió su PC”.

Elige Más información → Ejecutar de todas formas. La firma de código está en camino.

¿Cómo lo desinstalo?

Configuración › Aplicaciones › IsleBar › Desinstalar. Vuelve el cuadro de búsqueda normal y se eliminan los hooks de IsleBar (versión de Store: desactiva antes la conexión Claude Code / Codex en la configuración de IsleBar).

¿Qué idiomas?

English, 简体中文, 繁體中文, Français, Deutsch, Italiano, 日本語, 한국어, Português, Español — sigue el idioma de tu Windows.

¿Necesitas ayuda?

Algo no funciona, una idea o una pregunta — cuéntanoslo en GitHub o por correo.
