IsleBar

Your Windows 11 taskbar, alive. Ask Claude Code or Codex from the search box — and see when it is working, needs you, or is done.

Works great with

  • Claude Code or Codex CLI — ask from the bar and see working · needs you · done.
  • Everything (voidtools, free) — press Tab to search every file on your PC instantly.
  • Any web browser — web search results open there.

IsleBar runs on Windows 11 (x64), with the taskbar search box shown as a box or an icon.

Know where your agent is.

Working. Needs you. Done. The search box tells you — so you can look away while Claude Code or Codex works. An orange edge means it is waiting for your answer; green means it has finished.

One box. Everything else, too.

The pill stays where the search box always was. Only what is inside changes.

Ask from the taskbar.

Click the pill or press Ctrl+Alt+C, type what you want done, and press Enter. A terminal opens and runs Claude Code or Codex with your question.

  • ↑ ↓ bring back your last 50 questions.
  • Long questions get a preview above the bar; Shift+Enter opens a multi-line box.
  • The ⌄ button keeps your options: session, model, effort, permissions, remote control.

Drop a file, then ask.

Drop a screenshot or a log on the pill — its path lands in the box, ready for your question.

  • Set a Drop command in Settings to make dropping do something else.
  • How I use it: dropped files go straight to my phone over Telegram, through a small script of my own.

Codex, too.

Codex CLI gets exactly the same working · needs you · done. Its mark is read from the Codex extension already on your PC — IsleBar ships no OpenAI logo.

  • Orange — the agent is asking you something. Answer in the terminal and it goes back to working.
  • Green — done, with a soft chime. It stays until you look, click, or close the session.
  • Several sessions? The most urgent one shows, and a small dot means there is more.
  • Red — the plan's usage limit was hit (with the time it resets) or a turn stopped on an error, and why. At 90% of a usage window you get a heads-up first.

Timers in two keystrokes.

Type 25m, 90s or 1h 30m and press Enter. Only the digits that change roll over.

  • Hover for pause and stop. When it ends you hear a sound and the pill turns green.
  • Right-click for quick timers, Pomodoro (25 / 5 / 15 minutes, adjustable) and a Stopwatch.

Every file, instantly.

Press Tab and type — matches from every drive appear above the taskbar as you type, powered by Everything.

  • Enter opens, Ctrl+Enter shows it in File Explorer, Esc takes you back.
  • Tab again for web search, with an engine that fits your language.

Downloads, at a glance.

Downloads from Chrome, Edge, Firefox and other browsers show while they run, and Done with the file name when they finish. Click to see the file in File Explorer.

Music, tinted to the album.

Spotify, YouTube in your browser and most players show with album art, level bars and a progress line in the album's colour. Hover for ⏮ ⏯ ⏭.

If an agent finishes mid-song, the green border lights up without hiding the music.

Quiet notices.

Headphones, charging, internet, copied text, heavy CPU or memory, focus sessions, calendar events, microphone or camera in use — each shows for a moment, then gets out of the way. No pop-ups.

Colours mean one thing each: orange when an agent needs your answer, red when something needs fixing — a low battery, or an agent stopped by its usage limit or an error — and green when something is done. The chime stays quiet during Do Not Disturb, and can be muted over full-screen games and videos.

Light and dark.

IsleBar follows your Windows theme and recolours itself the moment you switch — no restart.

Questions

Is it free?

Yes — free and open source under the MIT License. Fixes, ideas and feedback are welcome on GitHub.

How do I get notified when Claude Code or Codex finishes on Windows?

Install IsleBar and connect Claude Code / Codex (one checkbox in setup). The bar turns orange when the agent needs your answer and green with a soft chime when it is done — no terminal-watching.

Do I need Claude Code or Codex?

Only for the AI part — asking from the bar and seeing working · needs you · done. Music, timers, downloads and notices work without them; file search needs Everything.

Does it send my data anywhere?

No. It runs on your PC. Crash reports are opt-in and carry only the error, versions and basic device info — never titles, files, prompts or your IP. Privacy policy.

Windows says “Windows protected your PC”.

Choose More info → Run anyway. Code signing is on the way.

How do I remove it?

Settings › Apps › IsleBar › Uninstall. The normal search box comes back and IsleBar's hooks are removed (Store version: turn off the Claude Code / Codex connection in IsleBar's settings first).

Which languages?

English, 简体中文, 繁體中文, Français, Deutsch, Italiano, 日本語, 한국어, Português, Español — it follows your Windows language.
