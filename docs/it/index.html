IsleBar

La tua barra di Windows 11, viva. Chiedi a Claude Code o Codex dalla casella di ricerca — e guarda quando è al lavoro, ha bisogno di te o ha finito.

Funziona alla grande con

  • Claude Code o Codex CLI — chiedi dalla barra e guarda: al lavoro · serve te · fatto.
  • Everything (voidtools, gratis) — premi Tab per cercare all'istante ogni file sul tuo PC.
  • Qualsiasi browser — i risultati della ricerca web si aprono lì.

IsleBar funziona su Windows 11 (x64), con la casella di ricerca della barra mostrata come casella o come icona.

Sappi sempre a che punto è il tuo agente.

Al lavoro. Serve te. Fatto. Te lo dice la casella di ricerca — così puoi distogliere lo sguardo mentre Claude Code o Codex lavora. Un bordo arancione vuol dire che aspetta una tua risposta; verde vuol dire che ha finito.

Una casella. E tutto il resto.

La pillola resta dove c'era sempre la casella di ricerca. Cambia solo quello che c'è dentro.

Chiedi dalla barra.

Fai clic sulla pillola o premi Ctrl+Alt+C, scrivi cosa vuoi fare e premi Enter. Si apre un terminale che avvia Claude Code o Codex con la tua domanda.

  • ↑ ↓ richiamano le tue ultime 50 domande.
  • Le domande lunghe hanno un'anteprima sopra la barra; Shift+Enter apre un campo su più righe.
  • Il pulsante ⌄ conserva le tue opzioni: sessione, modello, impegno, permessi, controllo remoto.

Trascina un file, poi chiedi.

Trascina uno screenshot o un log sulla pillola — il percorso finisce nella casella, pronto per la tua domanda.

  • Imposta un Comando di rilascio nelle Impostazioni per fargli fare qualcos'altro.
  • Come lo uso io: i file che trascino arrivano dritti sul mio telefono via Telegram, grazie a un piccolo script tutto mio.

Anche Codex.

Codex CLI ha esattamente lo stesso al lavoro · serve te · fatto. Il suo logo viene letto dall'estensione Codex già presente sul tuo PC — IsleBar non include alcun logo OpenAI.

  • Arancione — l'agente ti sta chiedendo qualcosa. Rispondi nel terminale e torna al lavoro.
  • Verde — fatto, con un suono delicato. Resta finché non guardi, fai clic o chiudi la sessione.
  • Più sessioni? Si vede la più urgente, e un puntino ti dice che ce ne sono altre.
  • Rosso — raggiunto il limite di utilizzo del piano (con l'orario in cui si azzera) o un turno fermato da un errore, con il motivo. Al 90% di una finestra arriva prima un avviso.

Timer in due tasti.

Scrivi 25m, 90s o 1h 30m e premi Enter. Scorrono solo le cifre che cambiano.

  • Passa sopra con il mouse per pausa e stop. Alla fine senti un suono e la pillola diventa verde.
  • Clic destro per timer rapidi, Pomodoro (25 / 5 / 15 minuti, regolabili) e un Cronometro.

Ogni file, all'istante.

Premi Tab e scrivi — i risultati da tutte le unità compaiono sopra la barra mentre digiti, grazie a Everything.

  • Enter apre, Ctrl+Enter mostra il file in Esplora file, Esc ti riporta indietro.
  • Ancora Tab per la ricerca web, con un motore adatto alla tua lingua.

Download a colpo d'occhio.

I download da Chrome, Edge, Firefox e altri browser compaiono mentre sono in corso, e con Fatto e il nome del file quando finiscono. Fai clic per vedere il file in Esplora file.

Musica nei colori dell'album.

Spotify, YouTube nel browser e la maggior parte dei player compaiono con copertina, barre di livello e una linea di avanzamento nel colore dell'album. Passa sopra con il mouse per ⏮ ⏯ ⏭.

Se un agente finisce a metà canzone, il bordo verde si accende senza nascondere la musica.

Notifiche discrete.

Cuffie, ricarica, internet, testo copiato, CPU o memoria sotto sforzo, sessioni di concentrazione, eventi del calendario, microfono o fotocamera in uso — ognuno compare per un attimo, poi si fa da parte. Nessun pop-up.

Ogni colore ha un solo significato: arancione quando un agente aspetta la tua risposta, rosso quando serve intervenire — batteria scarica, o un agente fermato dal limite di utilizzo o da un errore — e verde quando qualcosa è finito. Con “Non disturbare” il suono resta muto e si può silenziare durante giochi e video a schermo intero.

Chiaro e scuro.

IsleBar segue il tema di Windows e si ricolora nell'istante in cui lo cambi — senza riavviare.

Domande

È gratis?

Sì — gratuito e open source con licenza MIT. Correzioni, idee e feedback sono sempre benvenuti su GitHub.

È una Dynamic Island per Windows?

Nello spirito sì: una barra live stile Dynamic Island, ma si trova nella barra delle applicazioni di Windows 11, al posto della casella di ricerca, invece di fluttuare sullo schermo. È un'app indipendente, non un prodotto Apple.

Come ricevo un avviso su Windows quando Claude Code o Codex ha finito?

Installa IsleBar e collega Claude Code / Codex (una casella nel setup). La barra diventa arancione quando l'agente aspetta la tua risposta e verde con un suono leggero quando ha finito.

Mi servono Claude Code o Codex?

Solo per la parte AI — chiedere dalla barra e vedere al lavoro · serve te · fatto. Musica, timer, download e notifiche funzionano anche senza; la ricerca file richiede Everything.

Invia i miei dati da qualche parte?

No. Funziona sul tuo PC. I report sugli arresti anomali sono facoltativi e contengono solo l'errore, le versioni e dati base del dispositivo — mai titoli, file, prompt o il tuo IP. Informativa sulla privacy.

Windows dice “PC protetto da Windows”.

Scegli Ulteriori informazioni → Esegui comunque. La firma del codice è in arrivo.

Come lo rimuovo?

Impostazioni › App › IsleBar › Disinstalla. Torna la normale casella di ricerca e gli hook di IsleBar vengono rimossi (versione Store: prima disattiva la connessione Claude Code / Codex nelle impostazioni di IsleBar).

Quali lingue?

English, 简体中文, 繁體中文, Français, Deutsch, Italiano, 日本語, 한국어, Português, Español — segue la lingua di Windows.
